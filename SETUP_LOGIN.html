Google 로그인 설정

기존 로그인이 잘 된다면 다시 설정할 필요 없습니다. 실제 이메일은 Firebase 관리 화면에서만 선택합니다.

1. Google 켜기

  1. Firebase 관리 화면에서 사용할 프로젝트를 선택합니다.
  2. Authentication → 시작하기 → 로그인 방법(Sign-in method)으로 갑니다.
  3. Google을 선택합니다. 없으면 새 제공업체 추가 → Google을 누릅니다.
  4. 사용 설정을 켜고 공개용 앱 이름을 입력합니다. 지원 이메일은 본인 관리 계정을 선택하고 저장합니다.

지원 이메일은 Google 로그인 동의 화면에서 사용자에게 표시될 수 있습니다. 공개 GitHub 파일에 이메일을 넣을 필요는 없습니다.

2. 사이트 도메인 허용

  1. Authentication → 설정(Settings) → 승인된 도메인(Authorized domains) → 도메인 추가를 누릅니다.
  2. 사이트가 https://myname.github.io/my-dashboard/라면 myname.github.io만 입력합니다. 예시는 본인 주소로 바꿉니다.
  3. https://와 뒤의 /저장소이름/은 빼고 추가합니다. 기존 Firebase 기본 도메인은 유지합니다.

같은 GitHub 계정에서 저장소 이름만 바꿨다면 도메인은 같으므로 재등록할 필요 없습니다. 다른 GitHub 계정이나 별도 도메인으로 옮기면 새 도메인을 등록합니다.

3. 로그인 확인

  1. 사이트를 Chrome 또는 Samsung Internet에서 직접 엽니다.
  2. Google 계정으로 로그인을 누르고 계정을 선택합니다.
  3. 로그인 완료 후에도 일정이 잠겨 있다면 허용 목록과 규칙을 확인합니다.
  4. 로그아웃하면 목록과 수정 내용이 지워지고 입력이 잠겨야 합니다.

오류 해결

  • 승인되지 않은 도메인: 위 2번을 확인합니다.
  • 팝업 차단: 사이트의 팝업을 허용하고 다시 누릅니다. 앱 안에 열린 브라우저 대신 일반 브라우저를 사용합니다.
  • 로그인 준비 실패: 인터넷 연결과 config.js를 확인하고 로그인 준비 다시 시도를 누릅니다.
  • 새로고침 때 로그아웃: 시크릿 모드·사이트 데이터 자동 삭제 설정을 확인합니다.
